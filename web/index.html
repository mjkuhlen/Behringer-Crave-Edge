Getting started

    
    
      
  1. Connect the Crave over USB, then press ⟳ to rescan and pick BEHRINGER CRAVE in the device bar.
        No hardware? Choose Crave Simulator (built-in).
    2. 
      
  2. Click Connect. Several devices can be connected at once; each gets a chip below the header with its own play, stop and disconnect buttons.
    3. 
      
  3. Set App MIDI channel in Device Settings to match the rear-panel MIDI CHANNEL DIP switches.
    4. 
      
  4. Program steps in the Sequencer and press ▶.
    5. 
    


    
Tabs

    

      
Sequencer

      
32-step grid with per-step note, rest, accent, glide, velocity and gate. Length, swing, global gate and ratchet (1–4×) apply to the whole pattern.
        Dump from device reads a bank/pattern slot from the Crave; Write to device overwrites a slot and verifies it by readback.

      
Device Settings

      
Clock source/type/edge, ASSIGN output mode, accent threshold, pitch bend range, sequencer auto-play and MIDI clock out. Only changed values are sent as SysEx.
        Includes raw SysEx and a danger zone for clearing all 64 device slots.

      
Library

      
Saved patterns (JSON in the data volume). Back up all 64 device slots, restore them, import or delete.

      
Song

      
Chain saved patterns with repeats and transpose. The Crave has no song memory, so playback runs from the app.

      
Patch Notebook

      
Save cable routes, panel-control positions, notes, and restore checklists for patches that cannot be stored in the Crave as SysEx. The seeded guided recipe links software setup to the relevant physical hardware steps.

      
Modulation

      
App-side LFOs sent as CC, pitch bend or channel pressure. → ASSIGN routes a slot to the ASSIGN jack for patching.

      
Live Keys

      
On-screen keyboard; computer keys a w s e d f t g y h u j k.

      
MIDI Monitor

      
Every MIDI message in and out, including SysEx.

    


    
Playback modes

    
    
      
  • App playback (default): the app sends notes with swing, gate and ratchet. Ratchet, swing and global gate are not stored on the Crave.
    • 
      
  • Clock mode (⏱ on the device chip): ▶/■ send MIDI start/stop and 24 PPQN clock at the header BPM to drive the Crave's own sequencer. Set its clock source to USB or MIDI first.
    • 
      
  • Notes and the device sequencer fight each other. Starting app playback stops the clock on that device; stop the device sequencer before playing a song.
    • 
    


    
Things to know

    
    
      
  • Accent is velocity 112 or higher on the Crave; there is no separate accent bit.
    • 
      
  • Device writes are committed immediately. Back up first if the slot matters.
    • 
      
  • The Crave's knobs are analog and cannot be read or set over MIDI, so patch cables and knob positions are not saved by the app.
    • 
      
  • The server has no authentication. Use it on your own machine or a trusted network.
